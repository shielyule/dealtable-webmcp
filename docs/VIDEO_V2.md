## Hard rules (from v1)

1. **First 45 seconds = problem + one live proof.** Not architecture lecture.
2. **One feature per sentence.** Don’t explain WebMCP/HITL/Nemotron/Tavily in the same breath.
3. **Problem-first, not tech-first.**

| Tech-first (avoid) | Problem-first (use) |
| --- | --- |
| “We used WebMCP and seven tools” / “We used Nemotron + Tavily” | “You set a walkaway; agents shouldn’t cross it without you.” |
| Demo of tools | Demo of **one user** getting through a deal **safely** |
| Judges ask “why this stack?” | Judges think “of course the floor had to live on the page / in the mandate.” |

Your **written** voice (blog / Devpost) is stronger than ad‑lib — **borrow narration from that copy**. Fair game.

---

## Production tricks (help more than talent)

- **Script on a teleprompter** (or sticky notes beside the monitor) — **full sentences**, not bullets.
- **Record visuals first, voice second** — mute screen capture, then narrate over in one take (or two) with the script. Cuts “um” hard.
- Crop / maximize the app panel; judges need the **page**, not your desktop chrome.

## Beat sheet (~2–3 min)

Adapt numbers to the scenario you film (lease, freelance, insurance, etc.). One breath per line.

| Beat | Time | Show | Say (one breath) |
| --- | --- | --- | --- |
| **Problem** | 10s | Home or one slide | “You set a walkaway; agents shouldn’t cross it without you.” |
| **Mandate** | 15s | Setup fields | “Target, walkaway, concessions — the rules of the deal.” |
| **Agent + evidence** | ~30–40s | Counterparty reply + **Market check · Tavily** | “The other side answers with live comps — not a canned script.” *(Nebius: Nemotron counterparty; show source link on screen.)* |
| **Scoped waiver** | ~25s | Below-walkaway → **Grant waiver** card (floor + time) → Agent authority panel | “Below the floor they ask for a scoped waiver — you edit, grant, tools appear; revoke and they vanish.” |
| **Advisor / tools** *(if WebMCP in cut)* | ~20s | ChatGPT tool call → chat moves | “Advisor calls typed tools on the page, not the DOM.” |
| **Close** | 15s | Summary + handoff / export | “Audit trail and closure — practice that becomes paperwork.” |

**Nebius must-show on camera:** Tavily-backed line in the counterparty reply (Market check visible), then walkaway modal blocking a low offer. Both are on the request path for scoring.

Optional shorten if over time: drop Audit tab tourism; keep Mandate → live reply+comps → HITL → Summary.
